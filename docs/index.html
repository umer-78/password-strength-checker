How the score works

  1. Start from length × log2(pool) bits of brute-force entropy.
  2. Subtract bits for every pattern an attacker tries first: common passwords, dictionary words, keyboard walks, sequences, repeats, years.
  3. Map the result: <28 very weak, <36 weak, <60 fair, <80 strong, else very strong.
  4. Crack time assumes an offline attack at 10¹⁰ guesses/second.

A passphrase is capped at ~12.9 bits per word (Diceware-sized list), because attackers guess words whole.

Patterns it looks for

  • Whole-password hits on the built-in common list (123456, qwerty, …)
  • Leetspeak un-mapping: P@ssw0rd → password
  • Keyboard walks: qwer, asdf, 1qaz
  • Alphabet/digit sequences: abcd, 4321
  • Repeats: aaaaaaaa, ababab
  • Years and dates: 1998, 03/04/2026
